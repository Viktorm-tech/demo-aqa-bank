POST to http://localhost:8080/api/accounts

Body

{
    "customerId": "acc123",
    "initialBalance": 5.00,
    "currency": "EUR"
}

Headers

Accept: application/json, application/javascript, text/javascript, text/json
Content-Type: application/json

Curl

curl -v -X POST 'http://localhost:8080/api/accounts' -H 'Accept: application/json, application/javascript, text/javascript, text/json' -H 'Content-Type: application/json' -d '{ "customerId": "acc123", "initialBalance": 5.00, "currency": "EUR" }'
